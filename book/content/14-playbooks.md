## [III.0]{.sec}How to use this part [Must · ■□□]{.tag} {#s14-0}

Part I teaches each topic once and solves each question once. This part adds no new teaching. It answers a different question, namely "what should I do for this company, in what order, and when?", and it does so by reference: every question appears as a number that links to its solution. Consequently, the playbooks are short, and the mock papers are the only place where new questions appear.

[**Dates and tags** — the year is the year of the candidate report, not of the drive. **S** means the specific question was reported; **T** means the topic was reported and the wording is ours. Both come from anonymous, self-reported sources.]{.margin}Every playbook has the same five parts: (i) the process, with the years of the reports; (ii) what each round tests, with the sections to read; (iii) one paragraph on what is distinctive in the reports for that company; (iv) a seven-day plan; and (v) the reported questions. The reports are candidate accounts of the years 2019 to 2026, formats change, and a drive's own invitation always overrides this page.

**C1.** *Brute force* (partial marks): from each start, extend while at most two distinct letters are present, O(*n*²). *Optimal:* a variable window with a count array of 26. Extend the right end; while three distinct letters are present, shrink from the left with `while`, not `if`; record the width each step. Every index enters and leaves once, so the cost is O(*n*) time and O(1) space. Test `""` (0), `"a"` (1), `"abcabc"` (2) and a string of one letter.

```cpp
int longestTwoDistinct(const string& s) {
    int cnt[26] = {0}, distinct = 0, best = 0, left = 0;
    for (int right = 0; right < (int)s.size(); right++) {
        if (cnt[s[right] - 'a']++ == 0) distinct++;
        while (distinct > 2) {                      // shrink until valid again
            if (--cnt[s[left] - 'a'] == 0) distinct--;
            left++;
        }
        best = max(best, right - left + 1);
    }
    return best;
}
```

**C2.** *Brute force:* sort all points by squared distance, O(*n* log *n*). *Better:* a max-heap of size *k* on squared distance; push each point and pop the farthest when the size exceeds *k*, so O(*n* log *k*) time and O(*k*) space. Use squared distance in 64 bits: no square root is needed and the comparison is exact. Test *k* = *n*, *k* = 1 and ties.

```cpp
vector<pair<int,int>> kClosest(const vector<pair<int,int>>& pts, int k) {
    priority_queue<pair<long long, int>> heap;     // (squared distance, index)
    for (int i = 0; i < (int)pts.size(); i++) {
        long long d = 1LL * pts[i].first * pts[i].first
                    + 1LL * pts[i].second * pts[i].second;
        heap.push({d, i});
        if ((int)heap.size() > k) heap.pop();      // drop the farthest
    }
    vector<pair<int,int>> out;
    while (!heap.empty()) { out.push_back(pts[heap.top().second]); heap.pop(); }
    return out;
}
```

Both functions were checked against brute force on 2,000 random inputs each.

**C1.** *Brute force:* copy the nodes into an array and rebuild, O(*n*) time and O(*n*) space. *Optimal:* three steps on the list itself. (i) Find the middle with slow and fast pointers, testing `fast->next` before `fast->next->next`. (ii) Reverse the second half. (iii) Interleave the halves, saving the next pointers of both before re-linking. All steps are O(*n*) and use O(1) space. Test 0, 1, 2 and 3 nodes (`1 2 3` gives `1 3 2`), and even and odd lengths.

```c
void reorder(Node *head) {
    if (!head || !head->next) return;
    Node *slow = head, *fast = head;                 /* 1. find the middle */
    while (fast->next && fast->next->next) { slow = slow->next; fast = fast->next->next; }
    Node *second = reverse(slow->next);              /* 2. reverse the second half */
    slow->next = NULL;
    Node *first = head;                              /* 3. interleave */
    while (second) {
        Node *a = first->next, *b = second->next;
        first->next = second;
        second->next = a;
        first = a;
        second = b;
    }
}
```

`reverse` is the standard three-pointer reversal of [§1.6](#s1-6){.ref}.

**C2.** *Brute force:* count each value with a hash map, or sort and take the middle element; O(*n*) space or O(*n* log *n*) time. *Optimal:* Boyer–Moore voting. Keep a candidate and a count; a different value cancels one vote, and a value equal to the candidate adds one. A value with more than half of all votes cannot be cancelled completely, so it survives. If the problem does not guarantee a majority, a second pass must verify the candidate.

```c
int majority(const int *a, int n) {
    int cand = 0, count = 0;
    for (int i = 0; i < n; i++) {
        if (count == 0) cand = a[i];
        count += (a[i] == cand) ? 1 : -1;
    }
    return cand;                       /* valid because a majority exists */
}
```

Both functions were run on the examples and `reorder` was checked against an array model on 2,000 random lists.

### Answers and solutions {.break}

**P1.** There are six defects. (i) The function returns the address of a local array, which is dead when the function returns. (ii) `i <= n` copies *n* + 1 bytes. (iii) The result is never terminated. (iv) *n* ≥ 64 overflows `buf`. (v) *n* larger than `strlen(s)` reads past the end of `s`. (vi) `toupper` of a plain `char` that may be negative is undefined; cast to `unsigned char`. The fix allocates on the heap, so the caller must `free` the result. For "router-1" and *n* = 5 it returns `ROUTE`.

```c
char *upper_copy(const char *s, size_t n) {
    size_t len = strlen(s);
    if (n > len) n = len;                       /* never read past the terminator */
    char *out = malloc(n + 1);                  /* heap memory outlives the call */
    if (!out) return NULL;
    for (size_t i = 0; i < n; i++)
        out[i] = (char)toupper((unsigned char)s[i]);
    out[n] = '\0';                              /* terminate */
    return out;
}
```

**P2.** *Brute force:* copy the values into an array and rebuild, which breaks the "re-link, do not copy" rule. *Optimal:* hold the address of the link to rewrite, `Node **pp`, so the head needs no special case. For each pair `a`, `b = a->next`: point `a` past the pair, point `b` at `a`, store `b` in `*pp`, and advance `pp` to `&a->next`. O(*n*) time and O(1) space. Test 0, 1, 2, 3 nodes: 1 2 3 gives 2 1 3.

```c
Node *swap_pairs(Node *head) {
    Node **pp = &head;
    while (*pp && (*pp)->next) {
        Node *a = *pp, *b = a->next;
        a->next = b->next;                      /* a now points past the pair */
        b->next = a;                            /* b goes first */
        *pp = b;                                /* link the previous node (or head) to b */
        pp = &a->next;                          /* continue after the pair */
    }
    return head;
}
```

**P3.** *Brute force:* a hash map of counts, O(*n*) space. *Optimal:* XOR of all values is *x* ^ *y*, which is non-zero because *x* ≠ *y*. The lowest set bit of that value is a bit on which *x* and *y* differ. Splitting the array by that bit puts *x* and *y* in different groups, and each group, XORed, leaves one single value because the pairs cancel. `all & -all` isolates the bit. O(*n*) time, O(1) space.

```c
void two_singles(const int *a, int n, int *x, int *y) {
    int all = 0;
    for (int i = 0; i < n; i++) all ^= a[i];     /* all = x ^ y, nonzero */
    int low = all & -all;                         /* a bit where x and y differ */
    *x = *y = 0;
    for (int i = 0; i < n; i++) { if (a[i] & low) *x ^= a[i]; else *y ^= a[i]; }
}
```

**P4.** *Brute force:* generate every permutation in order, which is O(*n*!·*n*). *Optimal:* scan from the right for the first ascent, `a[i] < a[i+1]`. If none exists the array is the largest permutation, so reverse it. Otherwise swap `a[i]` with the rightmost element larger than it, then reverse the suffix after *i*, which was descending. O(*n*) time, O(1) space. Test all-equal (1 1 1 stays), one element, and the largest permutation.

```c
void next_permutation_c(int *a, int n) {
    int i = n - 2;
    while (i >= 0 && a[i] >= a[i + 1]) i--;      /* rightmost ascent */
    if (i >= 0) {
        int j = n - 1;
        while (a[j] <= a[i]) j--;                /* rightmost element larger than a[i] */
        int t = a[i]; a[i] = a[j]; a[j] = t;
    }
    rev(a, i + 1, n - 1);                        /* suffix is descending: make it ascending */
}
```

**C1.** *Brute force:* test every substring afresh, O(*n*³). *Better:* for each start, walk right keeping a balance (+1 for `(`, −1 for `)`); if the balance drops below zero no later end can repair this start, so break; each time it returns to zero count one substring. That is O(*n*²), which is ample for *n* ≤ 2,000, and the count needs `long long`. Test `)(` (0), `(()())` (4) and the empty string (0).

```c
long long balanced(const char *s) {
    int n = (int)strlen(s);
    long long count = 0;
    for (int i = 0; i < n; i++) {
        int bal = 0;
        for (int j = i; j < n; j++) {
            bal += (s[j] == '(') ? 1 : -1;
            if (bal < 0) break;               /* no later end can repair this start */
            if (bal == 0) count++;
        }
    }
    return count;
}
```

**C2.** *Method:* fold Euclid's algorithm over the array for the GCD, and fold `lcm = lcm / gcd(lcm, a) * a` for the LCM, dividing first so that the intermediate value does not overflow before it must. Use 64-bit unsigned variables. A single element is its own GCD and LCM. If the LCM may exceed 64 bits, stop and report overflow when `lcm / g > ULLONG_MAX / a`. O(*n* log *M*) time.

```c
static unsigned long long gcd(unsigned long long a, unsigned long long b) {
    while (b) { unsigned long long t = a % b; a = b; b = t; }
    return a;
}
void gcd_lcm(const unsigned *a, int n, unsigned long long *g, unsigned long long *l) {
    *g = a[0]; *l = a[0];
    for (int i = 1; i < n; i++) {
        *g = gcd(*g, a[i]);
        *l = *l / gcd(*l, a[i]) * a[i];        /* divide first to delay overflow */
    }
}
```

`balanced` was checked against a cubic brute force on 3,000 random strings; `gcd_lcm` gives 6 and 180 for 12, 18, 30, and 2 and 120 for 4, 6, 8, 10.

### Coding (in C++)

**C1. Bouquets.** A garden has *n* ≤ 10<sup>5</sup> flowers in a row; flower *i* blooms on day `bloom[i]`, 1 ≤ `bloom[i]` ≤ 10<sup>9</sup>. A bouquet needs *k* adjacent bloomed flowers, and each flower is used once. Return the earliest day on which *m* bouquets can be made, or −1 if *mk* > *n*. Examples: `{1,10,3,10,2}`, *m* = 3, *k* = 1 gives 3; the same with *k* = 2 gives −1; `{7,7,7,7,12,7,7}`, *m* = 2, *k* = 3 gives 12.

**C2. Least effort.** A grid of heights has *R* × *C* ≤ 10<sup>4</sup> cells. Moving to an adjacent cell costs the absolute height difference, and the *effort* of a route is the largest such cost on it. Return the smallest effort of any route from the top-left to the bottom-right cell. Example: `{{1,2,2},{3,8,2},{5,3,5}}` gives 2.

### Answers and solutions {.break}

**C1.** *Brute force:* for each day from the smallest to the largest bloom, count bouquets, O(*n*) per day and up to 10<sup>9</sup> days. *Optimal:* binary search on the answer. The test "can *m* bouquets be made by day *d*?" is monotone, because a later day never removes a bloom, and it costs one pass: count a run of bloomed flowers, close a bouquet at length *k*, and reset on an unbloomed flower. Search between the smallest and the largest bloom day for the first day that passes. O(*n* log *V*) time. Guard the early exit with `1LL * m * k > n`, since *mk* can overflow `int`.

```cpp
int minDays(const vector<int>& bloom, int m, int k) {
    long long n = bloom.size();
    if (1LL * m * k > n) return -1;
    auto feasible = [&](int day) {
        int bouquets = 0, run = 0;
        for (int b : bloom) {
            run = (b <= day) ? run + 1 : 0;
            if (run == k) { bouquets++; run = 0; }
        }
        return bouquets >= m;
    };
    int lo = *min_element(bloom.begin(), bloom.end());
    int hi = *max_element(bloom.begin(), bloom.end());
    while (lo < hi) {                               // first feasible day
        int mid = lo + (hi - lo) / 2;
        if (feasible(mid)) hi = mid; else lo = mid + 1;
    }
    return lo;
}
```

**C2.** *Brute force:* try every threshold and run a search over cells whose steps do not exceed it, O(*RC* · *V*). *Optimal:* Dijkstra in which the cost of a route is the maximum along it, not the sum: relax with `max(e, step)`. Skip stale heap entries, as in [§1.11](#s1-11){.ref}. O(*RC* log *RC*) time. Test a 1 × 1 grid (0), a single row, and equal heights (0).

```cpp
int minEffort(const vector<vector<int>>& h) {
    int R = h.size(), C = h[0].size();
    vector<vector<int>> best(R, vector<int>(C, INT_MAX));
    priority_queue<tuple<int,int,int>, vector<tuple<int,int,int>>, greater<>> pq;
    best[0][0] = 0; pq.push({0, 0, 0});
    const int dr[4] = {1, -1, 0, 0}, dc[4] = {0, 0, 1, -1};
    while (!pq.empty()) {
        auto [e, r, c] = pq.top(); pq.pop();
        if (e > best[r][c]) continue;               // stale entry
        if (r == R - 1 && c == C - 1) return e;
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr < 0 || nc < 0 || nr >= R || nc >= C) continue;
            int ne = max(e, abs(h[nr][nc] - h[r][c]));   // max, not sum
            if (ne < best[nr][nc]) { best[nr][nc] = ne; pq.push({ne, nr, nc}); }
        }
    }
    return 0;
}
```

Both were checked against brute force on thousands of random inputs and on the examples above.
